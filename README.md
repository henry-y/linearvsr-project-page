# LinearVSR project page

Static project page for *LinearVSR: Algorithm–System Co-Design for Real-Time Diffusion Video Super-Resolution*.

- `index.html`, `static/`: the page (served by GitHub Pages from the repository root).
- `remotion/`: source of the method and speed-race animations (`npm install && node render.mjs`).
- `tools/`: scripts that pull results from the inference cluster and regenerate `static/cases.json`.
